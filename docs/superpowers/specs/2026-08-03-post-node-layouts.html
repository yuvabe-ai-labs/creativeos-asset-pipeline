1 · Editor shell — approved

The Post focus view keeps the house shell: a bottom Sheet at h-[92vh], “Back to canvas”, an EditableField title, actions top-right — the same frame as the Draw and Prompt focus views. Four vertical bands inside it.

Alternatives considered and rejected

Rejected

Templates in the left panel

The original sketch. A permanent template browser is dead weight after the first click — the panel is idle for the entire rest of the session.

Rejected

Horizontal properties toolbar

Elegant for text, where font/size/weight/colour/align fit one row. Awkward for shapes and images, which have few controls, and there is no room for gradient stops.

Rejected

Single right panel, floating insert bar

Biggest canvas, fewest bands. But one panel doing Properties + Layers + Brand Kit fights itself the moment you want to drag a logo in while a layer is selected.

2 · First-run template picker

Shown over the stage when layers is empty. Choosing a template seeds the layer array and dismisses the overlay permanently. “Start blank” is always available.

3 · Template compositions

Templates are indexed by composition, not by marketing purpose — because composition is what decides whether a template fits the plate you have. Purpose is a tag on top. The purple dashed region is the copy zone: the area the template will cover, and therefore the area the Image Gen prompt must be told to keep clear.

Lower third

Full-bleed image, copy stacked in the bottom 35% over a scrim. The safest template — the scrim rescues almost any plate, so it works even when the image forgot to leave room.

offerpromotion copy zone: bottom 36%

Inset card

Image floats inset on a brand-coloured field; copy sits on the solid, never on the photo — so contrast is guaranteed and no scrim is needed. The most “designed” of the set.

launchannouncement plate: inset, top 43%

Side column

Vertical split — image one side, copy column the other. The only archetype with room for a real paragraph, so it is the one that survives long offer text. Reads well in landscape too.

offerbrochure copy zone: left 46%

Split half

Hard 50/50 between image and a brand colour block. The loudest option — built for a discount number or a big price. Also the one that most needs the palette to be right.

discountsale copy zone: bottom 50%

Deferred — not in v1

Both are cheap to add once real posts show whether anyone reaches for them.

Upper band

The mirror of Lower third. For plates whose subject sits low.

Centred hero

Maximum drama, one line of copy. Needs a plate with a calm middle.

The copy zone is a contract, not decoration. Each template declares its zone as a normalized rect, which renders into an Image brief sentence shown under the template name with a copy button — “leave the lower 35% of the frame clear and uncluttered”. That is what turns negative-space composition from luck into something repeatable. Display and copy only: nothing is written to another node, because edges run image-gen → post and auto-injection would be an upstream write from a downstream node. The human pastes it, and still presses generate.

4 · Layer anatomy

Four layer kinds, no more. Every layer's geometry is normalized to 0–1 of the canvas, so one composition renders at any output size — including A4 at 300 DPI (2480×3508).

KindProperties in the inspectorNotes
text content · family · size · weight · colour · align · line-height · letter-spacing · opacity Family comes from the curated webfont list; the client's default is pinned by font_primary in the KB.
shape fill · opacity · corner radius Rect only. A pill is a rect at radius 999. Covers CTA buttons, colour bands, price tags, dividers.
image source · fit (cover/contain) · opacity · corner radius Source is either a live binding to a connected node, or a URL from the Brand Kit / an upload.
scrim from · to · angle Linear gradient. Not decorative — it is what makes light text legible over a busy plate.

Wireframes are structural. Final visual design follows the Yuvabe system encoded in src/app/globals.css — Clash Display + Gilroy, purple #5829c7 used sparingly, neutrals doing the work, shadow-card elevation, easing cubic-bezier(0.22,1,0.36,1).
