Regenerate

R9.3–R9.4. The note is read here, beside the controls that fix it — which is why the popover stays a pointer. Regenerating writes a new version at pending, so the item leaves Dev's list and returns to Meera's. Neither side resubmits anything.

The loop closes on one existing rule. D29 already specifies that a regenerate produces a new version at pending. That single fact is what makes steps 8 → 3 automatic in both directions — no submit action, no resubmit action, and no assignee stored anywhere.
