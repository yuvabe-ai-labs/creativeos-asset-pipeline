How Client KB Gets Built

From brand materials → AI extraction → reviewed knowledge base

1
Team adds brand materials
🌐
Brand website URL (optional)
The system will scrape and summarise it automatically.
📄
Brand documents (optional)
Brand guidelines, tone-of-voice decks, campaign briefs — PDF, DOCX, PPTX, TXT. Up to 20 MB.
🖼️
Brand images (always optional)
Product photos, campaign imagery, mood boards — JPG, PNG, WebP. Up to 50 MB.
Minimum to start: a website URL or at least one document.
↓
2
Website research  — only if URL provided
🔍
AI scrapes the brand website
Fetches public pages and summarises the brand's positioning, voice, and visual language into a structured document.
💾
Research saved as a document
The summary is stored alongside the uploaded files — so the team can always see exactly what the AI pulled from the web before extraction ran. No black box.
↓
3
AI extraction — two things run at the same time
Running in parallel
📑
Document extraction
Reads all uploaded documents + website research. Fills ~33 brand knowledge fields.
Brand Voice Visual Identity Audience Image Direction Video Direction Compliance Rules
🎨
Image analysis
Visually reads the brand images. Fills 7 Image Analysis fields. Skipped if no images were uploaded.
Colours Mood Composition Lighting Aesthetic Subjects
📡
The UI shows live progress throughout — safe to close the tab and come back. The job keeps running.
↓
4
Results saved & KB unlocked for review
📝
Website research document stored
The Markdown summary from step 2 is saved as a permanent source document, linked to this KB version.
saved
🗂️
Versioned KB snapshot created
All 40+ extracted fields saved as a versioned record — which model was used, which docs were included, fill rate.
v1 saved
✅
Client status → In Review
The KB review page unlocks. Team gets a notification and the page refreshes automatically.
in_review
↓
!
If something goes wrong
🔴
Error shown in the UI
If the job fails at any point, the team sees an error message. The build can be restarted from scratch — no partial state is left behind.
⏱️
Stuck job recovery
If the job shows no progress for 10+ minutes, a "Clear stuck build" button appears so the team can reset and try again.
What happens next → Once the KB is built, the team reviews each field one by one — approve, edit, reject, or ask the AI to try again with extra context. When every field is reviewed, the KB is marked Ready and starts powering all content generation for that client.
